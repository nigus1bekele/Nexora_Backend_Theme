# Nexora Backend Theme

A clean, modern, and highly customizable backend theme suite built for **Odoo Community Edition (v18.0)**.

## Modules in this Repository

1. **[nexora_backend_theme](./nexora_backend_theme)**:
   The primary theme suite featuring:
   - Modern, responsive navigation bar and collapsible apps sidebar.
   - Comprehensive theme settings (`Settings > General Settings > Theme Settings`) for palette customization (topbar, sidebar, brand background, buttons, badges, and status colors).
   - Customized, branded authentication pages (Login, Sign up, Reset password) with configurable left info panel and custom background artwork.
   - Modernized OWL dialogs and interactive resizable chatter panel.
   - Dynamic business operations dashboard.

2. **[template_theme](./template_theme)**:
   A clean starter template module intended as a lightweight starting point for building custom Odoo backend themes.

## Installation

1. Copy or link `nexora_backend_theme` (and optionally `template_theme`) into your Odoo `addons` or `custom_addons` path.
2. Update your Odoo apps list (`Apps > Update Apps List` in Developer Mode).
3. Search for **Nexora Backend Theme Suite** and click **Install**.
